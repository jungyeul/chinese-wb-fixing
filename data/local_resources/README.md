# Local Runtime Resources

This directory is for local inputs used when rerunning scripts from raw
materials.

Expected optional files:

- `triplet_no_dup_threshold.csv`: glyph similarity table used by P2.
- CTB 5.1 can be passed as a segmented directory argument to
  `src/pipeline/dataset_construction/synthetic_ctb_generation/generate_synthetic_ctb.py`.
